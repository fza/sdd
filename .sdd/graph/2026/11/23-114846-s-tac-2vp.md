The defects a live test of the pinned `fza-next` build on two other projects of the owner found are fixed and merged on `fza-next`. The live test itself has no entry of its own; this done is its record in the graph. The fixes came through `next/fix-live-test-round` (f7ce434fd) and `next/fix-keyword-search` (274c8bca6):

- `sdd serve` over stdio exits within 0.4 seconds of a stop signal, inside the 0.5 seconds Claude Code allows before it kills the server, and its error names work still running; a title backfill ends at the stop and commits the titles it wrote (c2183a96d). This bounds the wait on background work that the shutdown kill (20261120-192705-d-tac-os2) left without a limit.
- Serve warns once per MCP client about the ranking judge that client's readings use, instead of warning at start about every judge (35a50333c).
- The error of a refused call says that its text questions still stand, so the agent answers them again instead of `lost` (45cb39843), correcting the required text question (20261122-234739-s-tac-vox). A move that ends on a `lost` or wrong answer lands on the base step in full, as the held-texts plan (20261122-105026-d-tac-wl5) sets for the response after such an answer.
- A served text names no cut for a stored value that the step only tests and never prints, as the capture dispatch did for the pre-flight rubric (05d135977, test 2d0c534ec); a refactor removes from the short landing a piece withdrawal that no landing reached, so nothing of it stays open (226577fce).
- Keyword terms match entry titles (59e9f36c3) and match as whole words in a graph check (f9afb0ed7); a graph check promises a search by meaning only where an embedding model is set (2fe4aaf5f); the embedding provider hint points at the user-global config (6fc3e50e0). These correct the graph check searches (20261122-230610-s-tac-k5o).
- Two deep-capture tests stay stable under machine load: a stalled round waits until the capture waits on it, and the hanging CLI stand-in records its PID only after forking its child (8809dfc4c).

The `resume_session` line for the last ended move, built in the same round, is recorded in 20261123-084712-d-tac-gw5.
