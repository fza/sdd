Deep captures no longer call the LLM pre-flight, and `llm.debug: true` writes a transcript of every LLM call, as directive 20261110-164357-d-tac-h1e commits. Commit 3e8cea63 adds the transcripts and ebe64e63 lets the deep verifier judge in pre-flight's place; both are merged into `fza-fork` in f16b76ad. A follow-up fix, 62b95f13 merged in baf7a03a, matches deep proposals whose fields hold `<`, `>` or `&`, pinned by `TestCaptureDeep_AProposalWithMarkupCharactersMatchesItsDraft`.

The acceptance criteria:

- No pre-flight model call under `deep`: holds. A deep capture's pre-flight runs only the mechanical checks. `TestCaptureDeep_TheVerifierJudgesInThePreflightModelsPlace` in `internal/proctest/capture_deep_test.go` counts no `preflight` call up to the dispatch and through the write. `preflight-extract` follows only a `preflight` call, so it does not run either. Prose captures keep their tests unchanged. Hooks on `capture.preflight` still fire, since a deep capture still passes the pre-flight step for the mechanical checks; no test runs a blocking hook under `deep`.
- Every rubric in the deep brief: holds by construction. `llmops.PreflightRubric` renders the pre-flight prompt the draft's shape selects, with the universal rules and the ref-kind vocabulary, plus the prose verifier's axes. The verifier reads it as page 2 of its reading, under "Pre-flight's rules". The test checks that the page is served; no test compares it rule by rule.
- A skipped deep exchange runs the pre-flight: holds. `TestCaptureDeep_ASkippedExchangeFallsBackToThePreflightModel` shows a weighed skip handing the draft to the pre-flight model, whose high finding blocks the write.
- One transcript per call under `llm.debug: true`: holds. `internal/llmdebug` writes one file per call, failed calls included, with purpose, provider, model, duration, token counts, both prompt parts, the response schema and the raw response. A transcript that cannot be written fails the call. `TestLLMDebugWritesATranscriptPerCall` in `internal/cliapp/llm_debug_test.go` shows transcripts written under the machine-local key and none while the key is unset.
- Committed config refused: holds. `llm.debug` joins the settings only a person's own config may make. `sdd config set` refuses it for the committed config through the shared ignored-settings check in `internal/handlers/handler_config.go`, and `model.HonoredCommitted` drops a committed value; the cliapp test shows a committed value turns no transcript on. No test runs the `sdd config set` refusal for this key itself.

A prose-mode capture on 2026-11-10 wrote one transcript per LLM call, for the gather query, the writing guide and the pre-flight, under `.sdd/tmp/llm-debug/`.

Beyond the directive, ebe64e63 serves each deep-exchange document, a reading page, the findings or the proposal, whole instead of at the store-value cap.
