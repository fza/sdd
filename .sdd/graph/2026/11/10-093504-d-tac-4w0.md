When a gate step holds, the engine lists only the conditions whose current value blocks a transition the step can still take, so the agent reads only work it owes (20261110-015634-s-tac-e4c). The flat held list across a gate's branches was first seen at the kind-conditional assemble gate (20260722-141852-s-tac-dhn); this rule removes it for transitions in every procedure.

**Selectors.** A predicate is registered as a selector when it reads a mode or state that no report can change: `autonomousDialogue`, `verifyBeforePlayback`, `noHookFindings` and `guideDue` among them. A selector chooses the path; it is never owed work. When a transition's guard fails on a selector, the transition is not on the step's path, and none of its conditions are listed. The remaining transitions list their failing non-selector conditions, deduplicated as now. The flag sits on the predicate registration, so every procedure gets the rule without spec changes.

**Negation.** The diagnostics evaluate each clause with its polarity. A predicate under `not` is listed only when it is true and that blocks the guard; a false predicate under `not` satisfies its clause and is not listed. Today every false predicate is listed regardless of `not`, which prints "the hooks' findings have not been weighed" in a project with no hooks.

Rejected:
- Diagnosing only the last conditional transition. It needs no new field, but it holds only while a spec puts its fallback last, a convention no loader checks.
- Listing every transition's conditions grouped by target. It hides nothing and needs no classification, but the list stays long and keeps internal predicate names a weaker agent may chase.

Accepted cost: every predicate author classifies the predicate. A selector marked wrongly as work shows noise again; work marked wrongly as a selector hides an owed line, so the default is not a selector.

## Acceptance criteria

- [ ] The `Predicate` registration carries a selector flag, off by default, set on the mode and state predicates the shipped procedures use.
- [ ] A transition whose guard fails on a selector contributes no diagnostic line.
- [ ] A predicate under `not` is listed only when its truth blocks the guard.
- [ ] A guided capture without hooks refused at `assemble` before any reading lists only the missing-reading line.
- [ ] An engine test over a synthetic spec covers a selector-gated transition and a negated clause.
