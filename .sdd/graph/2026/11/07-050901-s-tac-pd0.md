The deprecated text fields `ShowResult.Entries`, `SearchResult.Results` and `ViewResult.Sections` are gone from `pkg/application`, closing 20261101-192805-d-tac-ih7, the text-field gap 20261101-182713-s-tac-a00 and the view data-form gap 20261101-192945-s-tac-gm6, in commit `ff723055` on `pr/feat-view-sections`, merged into `fza-fork` as `cd1fb168`.

The application no longer renders text for these reads; the MCP server and the CLI render from `Items`, `Hits` and `ViewSections` as before, so their output is unchanged. `view` has had its data form since 20261101-205114-s-tac-g7z, which also deprecated the three fields. Tests that asserted on the text fields now render it through `test.ShowText`, `test.SearchText` and `test.ViewText` in the module's `test` package, with unchanged assertions. The removal ships in the first release after the deprecation release, as 20261101-192805-d-tac-ih7 set, and its release notes list it under Breaking.
