title: Fork version suffix stripped from `minimum_version` floor
summary: Fork builds record their upstream base as `minimum_version` by dropping a trailing `.fza.N` suffix before comparing or writing, so stock binaries of the base still accept graphs a fork creates or bumps; a fork on a stable base and graphs already recording a full fork version keep their suffix. A fork build records its upstream base as `minimum_version` in `.sdd/meta.json`, so stock sdd of that base keeps accepting a graph a fork binary creates or bumps. A fork release such as `v0.18.0-alpha.3.fza.45` is a valid semver pre-release that sorts above stock `v0.18.0-alpha.3`. Recorded as is, it makes stock `alpha.3` refuse the graph with "binary version v0.18.0-alpha.3 is below the graph's minimum_version v0.18.0-alpha.3.fza.45". The floor that `sdd init` records and `sdd init --bump` raises (20260507-231644-s-tac-1mx) therefore drops a trailing `.fza.N` before it compares or writes. A fork build on a stable base (`v0.18.0-fza.1`) keeps its suffix: stripped, the floor would sort above the fork binary itself. A graph that already records a full fork version keeps it: `--bump` only raises the floor, so such a graph is set back to its base by hand.

Rejected: release tags with build metadata (`v0.18.0-alpha.3+fza.46`), which semver ignores in comparisons. That changes the tag format, the release pipeline and the cask, and a graph already recording `alpha.3.fza.45` would refuse `alpha.3+fza.46`. Rejected: leaving the floor as the full fork version, which breaks any team mixing stock and fork binaries on a graph a fork release touched.

Accepted cost: one fork-only helper, and the floor no longer guards fork-only features; those need their own gate. The floor `sdd move` records (20261109-004305-s-tac-mp1) stays out of scope and needs its own decision. A released build, fork releases included, records its own full version, so a move made by a fork release still locks out stock builds of its base. A dev build records `v0.18.0-alpha.4`, which upstream `alpha.4` passes without reading move records.
