`sdd grounding update` finishes past failing subjects: a referencing entry whose request fails is recorded with its cause, the run goes on, the failures are listed at the end with a non-zero exit, and the next run scores the pairs left unscored.

This shipped on `fza-next` for `sdd grounding rescore` and `sdd grounding seed --from-refs` (d41c8f25, 3be4a206) and carried into `sdd grounding update` when it replaced both (57aadc3e).

d41c8f25 also added `--judge <name>` with the aliases `ranking` and `prefilter`. `sdd grounding update` scores with the ranking judge alone, the one `sdd grounding status` names, so `--judge` and its aliases no longer exist.

This replaces 20261118-162941-s-tac-450, which names `sdd grounding rescore`, `sdd grounding seed --from-refs` and `--judge` as the current surface. It extends the calibration commands of 20261114-003118-s-tac-0vl.
