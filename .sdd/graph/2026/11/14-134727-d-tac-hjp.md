The `dialogue.mode` value `autonomous` of 20261109-003920-d-tac-iap is renamed `auto`: `dialogue.mode` takes `guided` or `auto`. The mode's meaning is unchanged; only its value gets shorter.

The old value gets no alias. A config layer still carrying `dialogue.mode: autonomous` is read as 20261109-003920-d-tac-iap reads an unknown value, under the tolerant reads of 20260921-174543-d-cpt-tv9: sdd ignores it with a notice naming the file, the key and the allowed values, and the session runs guided, even where a lower layer sets `auto`, until the value is changed by hand. `sdd config set dialogue.mode autonomous` and `sdd init --dialogue-mode autonomous` are refused like any other unknown value, and the `sdd init` question writes `auto`. A session log that recorded `autonomous` stays readable: the mode in force comes from the config on each step.

Every check of the mode in served text compares against `auto`.

**Rejected.** Reading `autonomous` as an alias with a renamed notice: no config breaks, but the alias stays in code. Rewriting the value on `sdd init`: init would edit a personal file, and an upgrade without init still falls back to guided.

**Accepted cost.** Every config set to `autonomous` drops to guided after the upgrade, silently apart from the ignored-setting notice, until it is edited; every tool that writes the value has to write `auto`.

## Fulfilled when

- `dialogue.mode: auto` serves the autonomous wording of every base procedure; `guided` and an unset mode serve the guided wording.
- `dialogue.mode: autonomous` is reported as an ignored setting naming `guided` and `auto`, and the session runs guided, also when a lower layer sets `auto`.
- `sdd config set dialogue.mode autonomous` and `sdd init --dialogue-mode autonomous` are refused; both accept `auto`, and the `sdd init` question writes `auto`.
- A test fails when a base procedure compares `dialogueMode` against a value outside `guided` and `auto`.
- The configuration reference lists `dialogue.mode` among its keys, with the values `guided` and `auto`, the guided default and the personal layers that may set it.
