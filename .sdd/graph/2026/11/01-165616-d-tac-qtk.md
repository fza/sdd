With `sessions.token_saving: off` (20261101-164201-d-tac-sj4), the MCP results of `show`, `search` and every serve carry objects instead of rendered text:

- `show`: one object per entry, with id, title, kind, layer, status, summary, body, and its upstream and downstream items as objects (id, ref kind, entry kind, status, summary, ref description).
- `search`: one object per hit, with id, kind, layer, status, summary and score, beside the coverage it already returns.
- A serve: its instruction lanes as named objects (name, text) and its framing blocks as named objects, beside the report schema it already returns separately.

With `on` or no key, every result stays the text it is today. The object fields are new fields beside the text ones, each left empty in the other setting, so the declared output schema stays valid in both.

`off` already means that a hook on the machine handles sdd's output. That hook collapses what the agent already holds per entry, hit and lane, and today it can only find those by parsing sdd's text, whose layout no test in sdd keeps stable. Objects give it a shape sdd tests. Hosts without the hook keep text: Claude Code feeds the model `structuredContent` (20260831-193805-d-tac-ngj), and the same content as escaped JSON costs the model more tokens than markdown.

The objects come from the application: `Application.Show` and `Search` still return rendered text (`pkg/application/read_api.go`), so this work first makes them return structured results as 20260928-080143-d-cpt-kv4 commits. The MCP shell then renders text or objects from the same data. For `show` this defines the structured read shape 20260609-112244-s-tac-f7o found without an owner; the CLI's `--format json` stays open there.

Rejected:
- A key of its own for the shape. A machine running the hook would have to set two keys together for one fact.
- Keeping text and letting the hook parse it. sdd's layout would become a contract nothing in sdd tests.
- Objects for every host. Without the hook the model would read JSON instead of markdown, at a higher token cost.

Accepted cost: `show`, `search` and the serve each keep two result shapes, both tested. `token_saving` now means more than its name says: off also changes the result shape.

Fulfilled when, with `off`, `show`, `search` and serves return the object fields as listed and leave the text fields empty; with `on` or no key they return today's text unchanged; `Application.Show` and `Search` return structured results the CLI and MCP render from; and tests cover both settings for each tool.
