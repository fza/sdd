The topic-change sessions and the idle-session sweep of 20261121-223858-d-tac-cg2 are built and merged on `fza-next` (742c44550, b88f1e5a4): the session shell tells the agent to start a new session by itself when the ground topic changes, and the daily sweep removes an open session untouched for `sessions.retention` unless a move is in progress in it. The correction of fork point 28, 20261121-234844-d-tac-156, takes effect with it.

## Built

- Shell text (742c44550): in every dialogue mode the session shell's opening serve tells the agent to start a new session without asking the person when the ground topic changed, to keep the earlier handle, to leave that session unconcluded and to resume it when the topic returns. The promise that a session nobody ended stays resumable is gone. The rule that other dialogues are the user's to name admits the sessions the agent opened.
- Sweep (b88f1e5a4): `collectSessions` in `pkg/application/collect.go` also selects an open session whose last event is older than `sessions.retention` and that holds no move in progress, and removes it with its staged attachments. A session with a parked move or a move left mid-step stays, and so does one inside the retention. The idle time runs from the latest stored event, workflow event or metadata update.

## Criteria met

All eight: `TestUserDialogue_ATopicChangeStartsANewSession` in guided, auto and assisted mode (topic change, keep and resume the handle); `TestUserDialogue_ConcludeCarriesNoDischargeGate` and the regenerated `pkg/mcpapp` snapshot (the resumable promise gone, the other-dialogues rule); `TestCollectOpenSessions` with five cases and `TestStateSweepCollectsSessions` in `pkg/local` (removal past the retention, a parked move kept, a mid-step move kept, a session inside the retention kept). The help text of `sdd cache prune`, the configuration reference and the coding-agents guide state the rule for open sessions.

## Open

sdd does not check whether the ground topic changed; the judgement stays the agent's. An abandoned draft stays on disk until someone resumes or drops its move.
