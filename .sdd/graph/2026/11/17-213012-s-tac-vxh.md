`sdd serve --output-schema`, off by default, declares each MCP tool's SDK-derived `outputSchema` in `tools/list` again, which commit a9429711 had dropped to shrink the listing from 56,027 to 16,742 bytes: commit 3676c5df adds the `OutputSchema` option to `pkg/mcpapp`, and 9b17d9ec adds the flag and its configuration reference row, on `fza-next`. The flag's help text reads: "For debugging and for programs that read the replies as data, not through a model: lists each tool's reply schema. Agents don't need it."

The default stays off because the drop saves only wire bytes, no model tokens, in Claude Code: its model sees tool descriptions and input schemas, not output schemas. As with tool results (20260816-205521-s-tac-x9l), the host decides what reaches the model.
