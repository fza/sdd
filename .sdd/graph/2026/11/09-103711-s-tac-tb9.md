`sdd config` prints each configured hook as Go's default struct rendering, for example `{entry.written ./lint.sh 0 false}`, with no field names. The hooks-visibility fix (20261109-055231-s-tac-bwd) made `sdd config` list the hooks of every personal layer and left this rendering unchanged.

Expected, from the configured hooks directive (20261109-005138-d-tac-i61): a hook is an event, a command and an optional `timeout`, the same keys a person writes in the config, so the listing a person reads to check what runs shows them by those names.
