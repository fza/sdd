Entries captured over the hosted sdd server and over a local sdd server in the same project reach each other: an entry captured over hosted shows up locally, and one captured locally shows up over hosted. Felix Zandanel checked both directions on 2026-11-23 in another of his projects.

So the hosted server writes its entries to the graph repository behind it and reads commits made elsewhere. 20261114-143922-s-tac-ru4 saw commits made outside the hosted server reach that repository, but observed neither the server picking them up nor the server writing back. With two writers on one repository, the sync conflicts 20261030-113340-s-tac-42t lists can reach a hosted graph too; this does not answer that question's open points on resolving them.
