`sdd move` now records the fixed floor `v0.18.0-alpha.3.fza.43` as a moved graph's `minimum_version` and keeps a higher recorded one, as 20261111-090552-d-tac-bzr commits; built on branch `pr/feat-graph-move` in 15efb54e and merged into `fza-fork` in 5415c2eb.

`model.MoveMinimumVersion` takes the recorded floor and returns `model.MoveRecordsMinimumVersion` unless the recorded one is higher; the move handler no longer reads the binary version for the floor. `TestMoveMinimumVersion` and `TestMoveMinimumVersion_AdmitsOnlyBuildsReadingMoveRecords` cover the floor and the compatibility gate it sets. Each guard was broken and watched failing, then restored: the constant set to `alpha.4`, the floor emptied, the keep-higher branch disabled.
