In a guided capture the writing guide runs once, on the content the user approved, followed by the draft verifier, instead of between assemble and the first playback. This refines the timing of 20260810-141555-d-cpt-20r, which runs both guides before confirmation so findings become drafting input, and of the rollout that wired the writing guide between assemble and playback (20260811-141038-d-tac-rvu). In a guided dialogue the draft keeps changing in playback rounds, so a guide run before the first playback judges text about to change and never sees the user's edits; the gap 20260831-113619-s-tac-fsp records the result, every playback rewrite beyond the guide's reach.

- **Guided** (20261109-003920-d-tac-iap): the draft is shaped freely in playback rounds with no guide and no verifier. Once the user approves the content, the writing guide runs once, then the verifier (20261109-004729-d-cpt-xs5). If either changed something, the user confirms once more; only that last adjust gets a delta check of the changed lines.
- **Autonomous**: both run before playback, as today, since no dialogue edits follow.
- The guide still judges only once per capture, and its findings stay drafting input, never a gate.

This closes 20260831-113619-s-tac-fsp: after the guide's single pass nothing reaches the draft but the user's last confirm, and that confirm's changes get the delta check.

Rejected, with the reasoning: the guide before the first playback with the verifier at the end (dialogue edits never get a guide check, the gap stays open); the guide in both places (a second guide call per capture, and early hints on text that changes anyway).

Accepted costs: guide hints, like verifier findings, arrive after the user approved the content, so a finding can reopen a draft the user thought finished.

## Acceptance criteria

- [ ] In a guided capture, playback rounds run without the writing guide; the guide runs once after the user approves the content, then the verifier.
- [ ] If the guide or the verifier changed the draft, the user confirms again, and only a last adjust gets a delta check.
- [ ] In an autonomous capture both run before playback.
