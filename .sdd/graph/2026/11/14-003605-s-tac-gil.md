Lease-gated sync of the `sdd`-owned clones, fetch slices shared per bucket with a 10 percent push reserve, a per-minute limit and credits from unused slices are built on `pr/feat-git-credits` and merged into `fza-fork` at 7b43ac4d; this completes 20261113-232855-d-tac-1nz.

## Built

- e30f34aa: fetch slices and the credits idle slices earn, as pure model functions.
- 0be9e653: fetch cooldowns stretch to the bucket's slice, and credits pay inside a cooldown.
- a7b1b12d: credits are spent on pushes of written commits and on commanded syncs.
- d8cde075: config keys `lease_pause`, `read_wait`, `per_minute` and `per_minute_unauthenticated` with their minimums; `sdd config set` refuses values below them.
- b88c0510: a bucket's fetch slices are shared among the `sdd`-owned clones in the data directory; automatic fetches keep a 10 percent reserve; each bucket has a per-minute limit.
- 025e1808: the gate record keeps one lease per repository.
- a55d8aac: the serve timer fetches a clone only while its lease holds; a lease start waits at most `read_wait`; engine calls and reads renew leases.
- 4474359b, 5c0f744f, d30de734: docs for slices and credits, clone slices with the reserve and per-minute limits, and leases with the lease-gated timer.

## Acceptance criteria

- One shared lease per covered repository in the gate record: met (025e1808).
- Lease starts and renewals by session opening, engine calls and reads; end after `lease_pause`: met (a55d8aac).
- Coverage of `sdd`-owned clones only; a graph inside the code repository syncs as before: met (a55d8aac).
- Timer fetches only under a lease, once per effective cooldown, and pushes waiting commits regardless: met (a55d8aac).
- Lease start past the cooldown syncs once and waits at most `read_wait`, then serves with a notice; inside the cooldown it spends nothing: met (a55d8aac).
- The clone count per bucket, the effective cooldown and the 90 percent stop: met (0be9e653, b88c0510).
- Per-minute deferral: met (b88c0510, d8cde075).
- Credits earned by unused slices, aging out of the sliding hour: met (e30f34aa).
- Credit use limited to waiting pushes and commanded syncs, never after a failure, inside the hourly and per-minute limits, the floors and the concurrency cap; an empty wallet defers: met (0be9e653, a7b1b12d).
- Config keys read with minimums and refused by `sdd config set`: met (d8cde075).
- Configuration docs: met (4474359b, 5c0f744f, d30de734).

## Choices the decision left open

- The gate's ledger file stays at version 1; the new fields are additive.
- A credit is earned once an unused slice ends, dated when the slice came due.
- A credit-paid operation restarts its cooldown and its slice.
- An HTTPS repository whose login is not yet known earns and spends in both HTTPS wallets.
- Engine calls no longer sync on their own; leases do.
- The per-call refresh scope is removed, as leases already limit a call to one round per repository.
- CLI reads renew leases and wait for their background rounds before exiting.
- A remote given as a local path syncs on every lease start.

## Open

- No run with a real agent has used leases or credits yet: the Codex eval is blocked until 2026-12-09, and the running `sdd` server serves an older build until it is reconnected.
- In `sdd serve`, the refresh after a capture into a dependency runs in the background, and shutdown does not wait for it. It is normally a no-op, as the capture's engine calls already hold the lease.
- The narrowing to direct dependencies, 20261113-235859-d-cpt-l3m, is being built on top of this.
