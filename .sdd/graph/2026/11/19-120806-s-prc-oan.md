The fork released v0.18.0-alpha.3.fza.52 on 2026-11-19 as a prerelease of `fza/sdd` (https://github.com/fza/sdd/releases/tag/v0.18.0-alpha.3.fza.52), built from `fza-next` at `7f3c20fb` on upstream v0.18.0-alpha.3: binaries for macOS and Linux (amd64, arm64), checksums and `install.sh` from a release workflow run that succeeded, with the Homebrew cask `fza/tap/sdd` at the same version. It follows v0.18.0-alpha.3.fza.51 (20261118-201407-s-prc-o9t).

The release brings the fork's compatibility with stock sdd on a shared graph, project config and machine folders (20261119-120232-s-tac-4fz), and calibration in recall stages with `sdd grounding update` (20261119-105440-s-tac-5et).

Its notes list the breaking changes of both, and a chapter names where a team using both the fork and stock can fail and what the fork does differently.

The first published notes left out the grounding changes; the release text was corrected the same day and the projects using the fork were told.
