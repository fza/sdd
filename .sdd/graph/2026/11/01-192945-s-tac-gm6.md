`Application.View` returns its result only as rendered text (`ViewResult.Sections` in `pkg/application/read_api.go`), with no data form beside it, while 20260928-080143-d-cpt-kv4 expects the application to return data and leave rendering to the shells.

Actual: the MCP `view` tool (`pkg/mcpapp/tools.go`) and an engine query in `pkg/application/workflow_registry.go` read the text directly. A layout decides both what `view` selects and how it renders, so a data form has to carry sections, groups, entry lines and the layout's render choices, not just a list of entries.

Expected: `ViewResult` carries structured sections a shell renders, as `show` and `search` do after 20261101-192805-d-tac-ih7.
