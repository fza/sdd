`view` gets a public data form that mirrors the seven section shapes the view pipeline already produces, and its text comes from one renderer over that form, for the CLI and the MCP server alike.

- A public `ViewSection` in `pkg/application/types` names its render, its header name and the brief flag, and fills exactly one shape field: list, grouped, counts, focus block, participants block, WIP list or bodies. Each shape keeps what its renderer reads today, including rank scores, ref expansions, cut counts and pull hints.
- Entries in every shape use one public listed-entry type, the value the search and view entry lines are formatted from, so the entry line keeps a single formatter.
- One conversion from `query.ViewResult` to the public form feeds the CLI, the application and the presenter tests; output stays byte-identical, pinned by the existing view tests.
- `ViewResult` gains the sections beside `Sections`, which is deprecated and removed one release later, as 20261101-192805-d-tac-ih7 does for `show` and `search`. The engine query that returns the view text renders it through the shared renderer.
- Under `sessions.token_saving: off` the MCP `view` tool returns the sections as objects and leaves its text field empty, the rule 20261101-165616-d-tac-qtk set for `show` and `search`; with `on` its text is unchanged. The field names go to agentic-helpers, whose collapse hook reads these results.

Rejected:
- One generic row list for every section. Counts, focus and participants blocks and cut notes are not lists; flattening them loses their structure, and the renderer would have to guess it back.
- An untyped data value per section. Callers get no static type, and the MCP SDK cannot derive an output schema from it.
- MCP `view` as text only. It would be the one read outside the `token_saving` object rule.

Accepted cost: seven public shape types to maintain beside the internal ones, and a new MCP field set for the collapse hook to learn.

Fulfilled when CLI and MCP `view` text comes from the renderer over the public sections with output unchanged, MCP `view` returns objects under `token_saving: off`, and `Sections` is deprecated.
