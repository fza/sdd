`Application.Show` and `Search` still return rendered text (`ShowResult.Entries`, `SearchResult.Results` in `pkg/application/read_api.go`) beside their structured results, while 20260928-080143-d-cpt-kv4 expects the application to return data and leave rendering text to the shells over it.

Actual: the application fills the fields, through the shared renderer over the public types once 20261101-182333-d-tac-jiy lands, and their only consumer in this repository is the MCP server (`pkg/mcpapp/tools.go`). The CLI reads the finders directly. `ViewResult.Sections` is the same case for `view`, which has no data form yet.

Expected: the exported results carry data only, and the MCP server renders the text it serves from that data.

Removing the fields changes the exported `pkg/application` API, so every caller outside this repository that reads them breaks.
