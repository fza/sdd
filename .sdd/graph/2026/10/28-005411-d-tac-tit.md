Entry titles are an optional frontmatter field of graph schema 1: the binary's schema stays 1, schema 2 is removed, and a graph whose `.sdd/meta.json` records 2 is refused until its owners set it back to 1 by hand.

A title is a key older binaries already ignore on read, so it needs no format change. Schema 2 only guaranteed every entry a title, and it cost write access to everyone on a released upstream binary, which refuses any graph whose schema differs from its own. One format across the fork and upstream lets any sdd version write any graph without a migration.

Entries written under schema 2 differ from schema 1 only by the title key, which schema 1 now defines, so they stay readable as the read-compatibility contract (20260602-203349-d-cpt-i2x) requires, and setting `.sdd/meta.json` back to 1 is the whole conversion path.

This builds on the older-schema plan (20261027-092049-d-tac-7gz): its clause that writes schema-1 graphs without a title and refuses an explicit `--title` no longer holds, since schema 1 now defines the field. Its rejection of writing fields a schema does not define stands. The capability table, older-schema writes and the capabilities in `sdd info --format json` stay for later bumps.

Rejected: keeping schema 2 until upstream adopts it, since a migrated graph stays closed to upstream binaries meanwhile and the upstream pull request would carry a format bump for an optional field; reading a recorded 2 as 1, an alias the binary would carry as long as any graph records 2.

Accepted costs: an entry written by a binary without titles has none, so every surface that shows a title falls back to the summary when it is missing; the migration to schema 2 is removed; every graph already at 2 is blocked until someone sets its `.sdd/meta.json` back to 1 and commits it, and a user of a fork release who migrated meets the refusal unwarned.

## Acceptance criteria

- [ ] The binary's graph schema is 1 and schema 1 supports titles; no schema 2 exists.
- [ ] A capture on a schema-1 graph writes a title, and an explicit `--title` is accepted.
- [ ] An entry without a title reads, and every surface that shows a title falls back to the summary.
- [ ] A graph whose `.sdd/meta.json` records 2 is refused as unknown to the binary.
- [ ] This repository's `.sdd/meta.json` records 1.
