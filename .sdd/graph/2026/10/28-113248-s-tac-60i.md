The `claude-cli` LLM provider now runs the `claude` CLI apart from the caller's project tree and credentials, closing 20261028-113000-s-tac-ig4, in commit `04bf83f7` on branch `pr/feat-claude-cli-isolation`.

Each call starts `claude -p --safe-mode` in a fresh temporary working directory, removed after the call, so no project instruction files, skills, hooks or MCP servers load. The child's environment drops `ANTHROPIC_API_KEY`, `ANTHROPIC_AUTH_TOKEN`, `ANTHROPIC_BASE_URL`, `CLAUDE_CODE_USE_BEDROCK` and `CLAUDE_CODE_USE_VERTEX`, matched by variable name, so the call answers on the signed-in account. The README's LLM section states this and points key-based setups at `provider: anthropic`.
