The capture report field that names a staged file as the entry's body is `bodyHandle`. Its value is the `handle` the staging tool returns, and it completes the field family `body`, `bodyPatch`, `bodyHandle` that the staged-body directive (20261030-120506-d-tac-l2b) extends. The name holds whether the body was staged from a path or as content.

Rejected:
- `bodyFile`: reads as a file path, so an agent passes the local path instead of the handle; also wrong for a body staged as content.
- `bodyFrom`: does not say what the value is, a handle, a path or an entry ID, so the schema description carries the whole meaning.

Accepted cost: "handle" is sdd's own term; it is the key under which `stage_attachment` returns the handle.

## Acceptance criteria

- [ ] The capture report schema carries `bodyHandle`, described as the handle returned by the staging tool.
- [ ] A `bodyHandle` naming no staged file is refused, naming the handle.
