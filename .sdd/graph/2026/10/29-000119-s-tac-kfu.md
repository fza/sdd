Timed graph sync shipped in 10656875, 3db21bf4, bf01ec6f and d9705f1f: `sdd serve` syncs once per `sync.interval` under one lock shared by every process and worktree, and a blocked sync reaches every agent and command as a banner, with fix steps for one owning agent. It replaces 20261028-235331-s-tac-k3o, which left out the explicit-sync criterion.

**Plan criteria (20261028-175735-d-tac-k4y).** Each has a test; the timer also passed the smoke run of 20261028-235100-s-tac-2l3: rounds per interval; an unset, committed, malformed or sub-minute interval starts no timer and warns naming file and key, and `sdd config set` refuses it; timed rounds keep the auto-sync rules and the call cooldown; no two processes or worktrees sync at once; a held lock skips a round, while a publish waits and still reaches upstream. Stopping serve ends the timer (smoke run); the lock freed after a kill rests on flock, untested. The one-time notice criteria give way to the banner of 20261028-201909-d-tac-fxp.

**Refinements.** SyncStatus is pure and every fetch goes through FetchGraph (20261028-192101-d-tac-16h). A conflict pauses automatic sync until merged by hand, every response and command carries the banner, the owner gets the steps, `sdd info` shows the record, and an explicit `sdd sync` runs while blocked and records what remains (fxp). The banner prints once per invocation (20261028-204922-d-tac-gcl). The blocked-sync record is per branch (20261028-231901-d-tac-kr9) and ownership a 15-minute lease released on session end (20261028-233037-d-tac-1mc).

**Gaps.** A missing graph directory syncs no other repository (20261028-205140-s-tac-dgg); read responses carry the banner (20261028-003729-s-tac-mz0); a held push is reported once per command (20261028-004141-s-tac-4k8).

**In the doing.** Security review found git error text, which a remote can write, reaching the fix steps served to agents; failed fetches and pushes are now named by fixed descriptions.
