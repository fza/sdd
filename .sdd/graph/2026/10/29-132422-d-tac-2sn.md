A fresh interactive `sdd init` asks where the graph lives, and every interactive init asks the person's graph sync settings, so the split layout and per-person settings need no flags to discover. This refines the one-step split setup (20261029-130154-d-tac-frl), which reached a separate repository only through a typed `--project-dir`. Felix Zandanel chose these questions from the fork's settings that init did not ask: graph sync and the planned autonomous dialogue switch; contribution mode and LLM tuning stay out, as settings few fresh projects need.

Questions, on a terminal, using the promptkit surface (20260727-011759-d-tac-nq7):

- **Where the graph lives**, on a fresh init without `--project-dir`: in this repository (the default) or in a repository of its own. Choosing its own asks the project's path, defaulting to `../<this repository's folder>-sdd`, then the graph directory and language for that project; the setup then runs as `--project-dir` does.
- **Graph sync**, whenever no config layer sets `sync.mode`, as the participant is asked when unset: `manual` (the default) or `auto`; `auto` also asks `sync.interval`, empty meaning no timer. The answer goes to the `config.local.yaml` of the project holding the graph, since the mode is set per person (20261027-211908-d-tac-l8j); `manual` is written too, so the question is not repeated. `--sync-mode` and `--sync-interval` answer it without a terminal; without them a non-interactive init leaves sync unset.
- **Autonomous dialogue**: asked the same way once that switch exists; the question ships with the switch.

A project is set up only from a typed `--project-dir` or the answer to the first question. A `project_dir` recorded in a cloned repository, naming a folder without an sdd project, is refused with the advice to clone the project there: it names a shared project, and creating an empty one in its place would split the team's graph.

Rejected: asking every fork setting, since each question costs every fresh init. Rejected: writing sync answers to the committed config, which the per-person rule forbids.

Accepted costs: one or two more questions on interactive inits until sync is recorded; two more flags.
