The local graph store now answers the graph revision from each file's metadata while no graph file changed, and re-reads content only when one did, closing 20261028-113515-s-tac-0p4, in commit `16386d95` on branch `pr/feat-graph-revision`.

The store remembers its last revision together with a stamp per file: size, mode, modification and change time, inode and device. A later call walks the directory and compares stamps; equal stamps return the remembered revision, anything else hashes all content as before. The revision value itself is unchanged, so revisions recorded by older binaries still match. A stamp is not trusted when the file changed within two seconds of the check, since a write in the same clock tick can leave the stamp unchanged, and on platforms other than Linux and macOS, where inode and change time are not read; such a check always hashes content.
