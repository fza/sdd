Entry titles read in sentence case, like English chapter titles, and a command, identifier, or file or package name in a title is written as a backtick code span, so a title that opens with one keeps its lowercase first word: "`sdd` info JSON output", not "Sdd info JSON output".

## Behaviour

1. The exception lives in `model.CapitalizeTitle`, which all four title writers already call: the generated title, `--title` on `sdd new` and `sdd summarize`, and a corrected title in capture.
2. The title prompt (`internal/llmops/summary_templates/title.tmpl`) tells the model to write commands, identifiers, file and package names as backtick code spans anywhere in the title, and otherwise to start with a capital letter. Its example title is quoted in double quotes, so a backtick no longer reads as part of the example.

## Why

The capitalizer exists because listings show titles in a column and mixed casing reads as noise there. Applied without exception, it turns the name of a lowercase tool into a different word: "sdd" becomes "Sdd" in 39 stored titles of this graph, and even an explicit `--title` or a corrected title is changed. A code span marks the term as code for every reader, which is also what keeps it lowercase.

## Rejected alternatives

- A configured list of terms that stay lowercase. A new config key someone maintains, and any term missing from it is still capitalized.
- No capitalizer, the prompt alone. The model's casing is inconsistent again, and a lowercase title can no longer be told from a slip.

## Accepted costs

Backticks show as literal characters wherever a listing prints titles as plain text, and each span takes 2 of the prompt's 32 characters.

Out of scope: titles already stored keep their casing; regenerating them is separate work. Rendering code spans styled in a terminal listing is not part of this plan.

## Acceptance criteria

- [ ] `CapitalizeTitle` leaves a title opening with a backtick unchanged and still capitalizes every other title.
- [ ] `sdd new --title` and `sdd summarize --title` with "`sdd` info JSON output" store exactly that title.
- [ ] A title opening with a backtick reads back unchanged after the frontmatter round trip.
- [ ] The rendered title prompt contains the code-span rule and no longer shows its example inside backticks.
