sdd now reads and parses the graph's entry files on all available cores and looks up an attachment directory only for entries that have one, closing 20261028-113109-s-tac-b5m, in commit `dd129ac2` on branch `pr/feat-graph-load`.

The directory walk only collects entry paths and the directories it passes. Reading the files and parsing them then run on one worker per available core, each result kept in its entry's own slot, so the loaded graph and its load issues stay in walk order. An entry's attachment directory is listed only when the walk saw it; an entry without one costs no filesystem call. A file that cannot be read still fails the whole load, now reporting every unreadable file at once.
