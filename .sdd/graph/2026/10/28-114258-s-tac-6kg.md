A release or docs build run in any GitHub repository now publishes to that repository, with an installer and docs site pointing back at it, closing 20261028-113918-s-tac-c79, in commits `ad8615e9` and `b81e9716` on branch `pr/feat-fork-release`.

The GitHub release, the Homebrew tap repository and the cask homepage take their owner from the `GITHUB_REPOSITORY_OWNER` that GitHub Actions sets. The release workflow attaches a copy of `install.sh` rewritten to download from the running repository's releases; the committed file stays unchanged. The docs site derives its Pages domain and GitHub link from `GITHUB_REPOSITORY`, falling back to `networkteam/sdd` outside Actions. A run in the original repository produces the same release, tap update and site as before. A repository whose releases are all prereleases can set the Actions variable `HOMEBREW_CASK_SKIP_UPLOAD` to `false` to update its tap anyway; unset, prerelease tags still skip the cask.

Commit `b81e9716` adds a note to the Claude agent instructions saying which remotes an agent may push to.
