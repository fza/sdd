Graph schema version 2 is unassigned: it was introduced for titles by mistake and reverted, so the next format change that needs a new schema takes the number 2, and sdd gives a graph recording 2 no handling of its own.

The titles directive (20261028-005411-d-tac-tit) removed schema 2 and expected a graph recording it to be refused as unknown to the binary. The gap 20261028-090103-s-tac-mj2 found that such a graph is refused only on a write, while reads still run. That gap is closed without a change: schema 2 was never released as a real format, the graphs that recorded it are set back to 1, and a refusal tied to the old meaning of 2 would collide with the next schema that takes the number.

A graph recording any schema the binary does not know keeps today's behavior: reads run, writes are refused.

Rejected: refusing every command on a graph at 2, or warning on reads with the hand fix. Both carry the withdrawn meaning of 2 into code that the next real schema 2 must remove again.
