One-step split repository setup in `sdd init` is delivered on branch `pr/feat-split-init`, in commits `19088720`, `51d1322b`, `3dea1ef0`, `aacc1629` and `26ba364a`.

Setup of a missing project (20261029-130154-d-tac-frl): `sdd init --project-dir <path>` creates a missing `<path>`, runs `git init` there outside any repository, and uses a repository rooted at `<path>` as it stands, its remote deriving `repo_id`. A `<path>` inside the work repository, inside another repository whose root it is not, or enclosing the work repository is refused before anything is written. The project's setup is a plain init there: `--graph-dir` and `--language` configure it, prompted on a terminal, `--language` required without one; `--participant`, `--agents` and `--scope` serve both. Each repository gets its own commit. An existing project keeps today's path, with `--graph-dir` and `--language` refused beside it, and a re-run after a failure past the project's commit finishes through it.

Questions (20261029-132422-d-tac-2sn): a fresh interactive init asks where the graph lives, then the project's path (default `../<folder>-sdd`), graph directory and language. Sync mode is asked when no config layer sets it, and the interval when the mode is `auto`, both written to the `config.local.yaml` of the project holding the graph; `--sync-mode` and `--sync-interval` answer without a terminal. A `project_dir` recorded in a clone, naming a folder without a project, is refused with clone advice. The autonomous dialogue question is not part of this delivery: it ships with that switch, still to be built.

Refresh of both repositories (20261029-132740-d-tac-g32): every init in a work repository first runs the project's init with the project's own recorded settings, its failure stopping the run, then the work repository's. Both `.gitignore` files receive the same entry set.

Added in the doing: a `graph_dir` that would read as more than one ignore rule (a newline, a leading `!` or `#`) is refused, since it lands in `.gitignore`. The project's refresh keeps its own skill scope rather than the work repository's `--scope`. A detached HEAD in the project no longer blocks the refresh.

The branch was cut from the stacked lineage (`pr/feat-timed-graph-sync`); the entries recording the `project_dir` layout (20261028-115146-s-tac-15i), which the setup builds on, were missing there and were brought onto the branch; no code changed with them.

Stays open: a re-run after a failed init commit still reports success with the setup uncommitted (20261029-143251-s-tac-kic). The evaluation (20261029-142339-s-tac-yw8) covers the code review and a terminal run of the built binary.
