Timed graph sync shipped on branch pr/feat-timed-graph-sync in 10656875, 3db21bf4, bf01ec6f and d9705f1f: `sdd serve` syncs the graph once per `sync.interval` under one lock shared by every process and worktree, and a blocked sync reaches every agent and command as a banner, with fix steps for one owning agent.

**Plan criteria (20261028-175735-d-tac-k4y).** Each has a test, the timer also the smoke run of 20261028-235100-s-tac-2l3: rounds per interval; an interval that is unset, committed, malformed or under a minute starts no timer and warns naming file and key, and `sdd config set` refuses it; timed rounds keep the auto-sync rules and the call cooldown; no two processes or worktrees sync at once (race test against a bare remote); a held lock skips a round, while a publish waits and still reaches upstream. Stopping serve ends the timer, seen in the smoke run; the lock freed after a kill rests on flock and has no test. The one-time notice criteria give way to the banner of 20261028-201909-d-tac-fxp.

**Refinements.** SyncStatus is pure and every fetch goes through FetchGraph (20261028-192101-d-tac-16h). A conflict pauses all automatic sync until merged by hand, every response and command carries the banner, the owner gets the steps and `sdd info` shows the record (fxp). The banner prints once per invocation (20261028-204922-d-tac-gcl). The blocked-sync record is per branch (20261028-231901-d-tac-kr9) and ownership a 15-minute lease released on session end (20261028-233037-d-tac-1mc).

**Gaps.** A missing graph directory no longer syncs another repository (20261028-205140-s-tac-dgg); read responses carry the banner (20261028-003729-s-tac-mz0); a held push is reported once per command (20261028-004141-s-tac-4k8).

**In the doing.** Security review found that git error text, which a remote can write, reached the fix steps served to agents; failed fetches and pushes are now named by fixed descriptions.
