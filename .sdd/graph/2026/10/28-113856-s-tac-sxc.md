A run can now take the machine-local config layer from any file through the global `--local-config <path>` flag, closing 20261028-113628-s-tac-fnt, in commit `cf7feaa9` on branch `pr/feat-local-config`.

The path, made absolute, replaces `.sdd/config.local.yaml` for the whole invocation: config resolution, `sdd config` and its provenance view, the unknown-key check, and `sdd config set --local` / `unset --local` all use it. With the flag, a directory without `.sdd/` still gets a machine-local layer. The README's config section documents it with an example.

One write path is not wired: the CLI never sets the new `InitCmd.LocalConfigPath`, so `sdd init --participant` still writes `.sdd/config.local.yaml` under `--local-config`. Config resolved for the MCP server's registered checkouts (`pkg/local.NewRepositoryTargets`) also keeps each checkout's own file.
