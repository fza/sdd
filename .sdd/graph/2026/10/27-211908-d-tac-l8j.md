`sync.mode` is set per person: only the user-global config and the untracked `.sdd/config.local.yaml` may set it, and a value sdd must not honor leaves sync manual with a warning instead of stopping sdd from running. This refines the automatic sync plan (20261027-194536-d-tac-190), which let any layer set the mode, the committed `.sdd/config.yaml` included, and refused an unknown value at config load.

A committed setting would let anyone with commit access switch publishing on for every clone: each participant's captures would start reaching the upstream without that participant opting in. Opt-in therefore belongs to the person whose captures get published. The accepted cost: a team cannot switch everyone on in one place, and each participant opts in once. A committed team-wide switch that each participant confirms locally was rejected: two settings to keep in step, plus reporting for a committed value that does nothing alone.

Reading stays tolerant, per the config rule (20260921-174543-d-cpt-tv9). A `sync.mode` in the committed config, or a value other than `manual` or `auto` in any layer, is ignored, leaving the mode `manual`, and reported as a warning on every run naming the file and key. Writing stays strict: `sdd config set sync.mode` refuses any other value. Refusing at read was rejected because a newer sdd adding a mode would stop older versions on the same machine from starting, the failure that rule exists to prevent. The accepted cost: a mistyped `auto` leaves sync off until the warning is acted on.

The plan's first acceptance criterion is replaced by the two below; its other criteria stand.

## Acceptance criteria

- [ ] `sync.mode` takes `manual` or `auto` in the user-global config and in `.sdd/config.local.yaml`, an unset value means `manual`, and the local layer overrides the global one.
- [ ] A `sync.mode` in the committed `.sdd/config.yaml`, or a value other than `manual` or `auto` in any layer, leaves the mode `manual`, lets every command run, and is reported as a warning naming the file and key; `sdd config set sync.mode` refuses a value other than `manual` or `auto`.
