Commit `7c96297c` on branch `pr/feat-merge-entry` fixes all five `sdd merge-entry` defects of the gap 20261030-125047-s-tac-gar:

1. Setup writes the driver command before its name, so a failed second write leaves a working driver rather than a named one without a command.
2. Init routes only entry paths: the attribute pattern is the graph directory followed by `model.EntryPathGlob`, `YYYY/MM/DD-*.md` as digit classes. Under `graph_dir: .` a README, an attachment's Markdown and a WIP marker stay with git's own merge, each confirmed by `git check-attr`.
3. A key's lines end before a closing run of column-0 comment lines, so a comment below `title` or `summary` stays where it is. A run of blank lines alone stays with the key, as a kept block scalar owns it, and an indented `#` line inside a block scalar stays part of the value.
4. The step writing resolved fields into all three versions is `model.ResolveDerivedFields`; the handler calls it.
5. A driver setup failing after the commit names the commit as landed, so the caller does not repeat the write.

10 new guards were broken one at a time, each caught by its own assertion and restored byte-identically. A three-clone smoke run on the rebuilt binary writes the narrowed pattern, merges two different summaries without a conflict, and leaves both between markers with an `sdd` exiting 3. Not yet merged into `pr/core` or `fza-fork`.
