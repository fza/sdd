A long entry now captures under the default LLM setup: on branch `pr/fix-claude-cli-timeout`, started from upstream `main` as a code-only bugfix, commits `ce04ea58`, `6a357a42`, `84e36b1f` and `a04d63e2` give `claude-cli` calls a 5-minute default, name `llm.timeout` when a call runs out its bound, show the default in `sdd config`, and run `claude -p` with no tools.

- The default `llm.timeout` is 5 minutes for the `claude-cli` provider and stays 2 minutes for every other provider; Felix Zandanel settled the split after a timed run, with `llm.timeout` raised so nothing was cut off, had shown the writing guide taking 153 to 211 seconds on the 5.3 KB directive.
- A call that runs out the configured bound fails with the bound and `sdd config set llm.timeout <duration>` in its error, on every provider and on the CLI and MCP paths alike; a deadline the caller set itself is passed through unchanged.
- `sdd config` and `sdd config get llm.timeout` show the timeout in effect, following the provider. `llm.extract_timeout` exists only in the fork, not in upstream `main`, so this fix leaves its display open there.
- `claude -p` runs with `--tools ""` and `--strict-mcp-config`. With built-in tools off but the configured MCP servers loaded, a two-word prompt cost about nine times as much, because the MCP tool definitions then entered the prompt in full (`84e36b1f` reverted that first attempt); with neither, it cost about half of stock. A draft's text also has no tool left to act through.
- A tool that needs the limit, such as agentic-capture, reads it through `sdd config get llm.timeout`; `sdd info` gains no field for it.

End to end, the fixed build with no `llm` configuration captured the same directive over MCP: pre-flight in 62 seconds, writing guide in 221 seconds, and well under half the input tokens of upstream `main` per call (19.6k against 47.5k for pre-flight, 15.3k against 43.7k for the writing guide), every call through `claude -p` under a configuration isolated from the user's. Those timings leave little room under 5 minutes for entries much longer than 5 KB.
