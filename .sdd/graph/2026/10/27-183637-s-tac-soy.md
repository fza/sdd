Commit 6ab906a8 on branch `feat/unified-title-rule`, merged into `fza`, renders one title rule from a single Go source into every place a title is written, closing the unified title rule plan (20261027-182551-d-tac-9t5) and the gap that agents writing a title got none of the title guidance (20261027-181119-s-tac-fgt).

`model.TitleRule` holds the rule: a noun phrase of 3 to 10 plain words, about 30 to 80 characters, starting with a capital letter, with commands, identifiers, file and package names and any other name whose own spelling starts lowercase written as backtick code spans in their own casing. The title prompt (`internal/llmops/summary_templates/title.tmpl`) renders it for the model, the `--title` help of `sdd new` and `sdd summarize` appends it, and the capture procedure's verifySummary step injects it through a new engine query, `titleRule`; the `correctedTitle` field description points at that rule.

The plan wrote the rule by hand into four places, kept in step by tests. The single-source contract (20260614-110729-d-cpt-chi) forbids hand-maintained duplicate instruction text, so the rule is rendered from one constant instead, and that accepted cost of the plan no longer applies.

The flag help names its value placeholder `TITLE` first, because urfave/cli takes a usage string's first backtick pair as the placeholder and strips its backticks; unnamed, the help read `--title sdd` and lost the code span of its own example.

Acceptance criteria:

- The title and summary prompts state the rule, including names that start lowercase and the length guidance, and no longer say at most 32 characters (`internal/llmops/summary_test.go`).
- The verifySummary instructions state the rule (`internal/proctest/capture_title_test.go`); the `correctedTitle` description refers to it.
- The `--title` help of `sdd new` and `sdd summarize` states the rule, and the `sdd new` help no longer claims the title is stored verbatim, since a first letter that is not a backtick is still capitalized (`internal/cliapp/title_help_test.go`).
- A `--title` over 80 characters is stored in full (`internal/handlers/handler_new_entry_test.go`).

Removing the rule from the prompt, from the capture step and from the `sdd new` help, dropping the `TITLE` placeholder, and adding an 80-character cut each failed its own test. Whether models and agents follow the wider rule in use was not checked.
