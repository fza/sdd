Commits af5cef73 and e13177b9 on branch feat/contribution-mode, merged into the fork's mainline, deliver contribution mode as 20261027-092131-d-tac-t7g describes.

`contribution: <upstream ref>` in a checkout's `.sdd/config.local.yaml` turns the mode on. `sdd config set --local contribution origin/main` writes it, and a committed `config.yaml` carrying the key is refused. `model.ContributionRefusal` decides, and `git.CLI.CheckContribution` gathers the facts: the checkout's branch, the branch the ref names, and `git merge-base --is-ancestor`. A graph write is refused on a detached checkout, on `default_branch`, on the ref's branch, on a branch not cut from the ref, and when the ref does not resolve; each refusal names its cause. The CLI applies the guard to `sdd new`, `sdd rewrite`, `sdd summarize`, `sdd wip start` and `sdd wip done`. The engine applies it in the repository targets' write factory to every acquired checkout, judged by that checkout's own config, so a `bind_branch` target answers for itself. `sdd info`, `mcp__sdd__info` (`contribution`) and the session framing show `Mode: contribution (<ref>)`. The bundled sdd skill carries a one-paragraph pointer naming the mode and when to use it, and the Codex render validates.

Every acceptance criterion has a test, through both the CLI and the production repository targets. All 25 guards were broken once, each failing its own test. The full suite and lint pass on the branch and on the merge.

Three choices differ from the plan's decomposition. The CLI guard is one wrapper in `internal/cliapp` around the five write commands rather than a check in each handler, so it runs once and before any model call. The serve banner is the session framing: `sdd serve` prints no banner on stdio. The skill section is a pointer rather than a procedure: the skill names features and leaves procedure to what the engine serves.

One gap remains. A work repository that points at its graph with `project_dir` accepts only `project_dir` in its machine-local config, so contribution mode cannot be switched on there.
