Up to release v0.18.0-alpha.2, sdd's Homebrew cask clears the macOS quarantine attribute through a GoReleaser option that GoReleaser v2 has deprecated, so the release run reports a deprecation notice for it.

Expected, as a natural expectation: the release configuration uses the options its tool currently supports, because the release workflow installs the newest GoReleaser v2 (`version: "~> v2"` in `.github/workflows/release.yaml`) and a deprecated option is one a later v2 release may drop.

Actual, in v0.18.0-alpha.2: `.goreleaser.yaml` sets `homebrew_casks.hooks.post.install` to a Ruby `if OS.mac?` block that calls `system_command "/usr/bin/xattr"` on `#{staged_path}/sdd`. GoReleaser v2.19.0 marks the `install` hook field deprecated in favour of `install_steps` and emits the deprecation notice `homebrew_casks.hooks.post.install` whenever it is set, as its source shows (`pkg/config/config.go`, `internal/pipe/cask/cask.go`).
