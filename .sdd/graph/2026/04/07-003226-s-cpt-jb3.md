title: Open signal definition
summary: 'Identifies a definitional gap in how "open signals" should be computed: signals lacking any decision reference should be flagged as unaddressed, determinable through graph traversal without manual tracking. This clarifies the operational contract (20260406-115547-d-cpt-o8t) by specifying how catchup and status commands should mechanically identify which signals remain active versus resolved.'
---

Open signals should be defined as signals not referenced by any decision. If a decision refs a signal, that signal is addressed. This is computable by traversing the graph — no manual bookkeeping. The catchup and status commands should use this definition.
