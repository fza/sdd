title: Auto-commit on entry creation
summary: Establishes a directive to auto-commit every new SDD entry immediately upon creation, treating each entry as immutable and eliminating deferral risk. This decision directly resolves the commit granularity question (20260408-093827-s-prc-9yt) by guaranteeing entry durability and visibility across concurrent sessions while avoiding merge conflicts through one file per commit.
---

Auto-commit on every sdd new. The CLI creates the entry file and immediately commits it. Each entry is an immutable file that never changes after creation — no reason to defer. Immediate commits ensure entries are durable and visible to concurrent sessions. One file per commit, no merge conflicts.
